# bic

**blockchain + agents**

Construyo herramientas para que los agentes de IA trabajen mejor — y productos con ellos.
Montevideo, Uruguay.

## Stack

- **TypeScript / Next.js / React 19** — interfaces, dashboards y plantillas base (Tailwind v4, shadcn/Base UI)
- **Rust** — servidores MCP, TUIs y tooling para agentes
- **Python** — pipelines y utilidades

## En qué estoy

- Servidores MCP (Model Context Protocol) y tooling para agentes de IA
- Plantillas reutilizables para arrancar proyectos rápido
- Interfaces tipo red social para trabajar con agentes: feed de entregables, historias en tiempo real, mensajes como instrucciones
